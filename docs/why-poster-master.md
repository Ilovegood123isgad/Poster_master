# 为什么这样设计

[English](en/why-poster-master.md) · [文档索引](README.md)

这份文档写给**要改这个技能包的人**。先说清楚边界，再说你能改什么。

## 它不是什么

它不是海报模板库。模板给的是固定版面，而这个技能面对的是"每次都不一样"的需求。

它也不是一次性的提示词。海报项目会跨天、跨人、跨轮对话，
所以流程、产物和状态必须落在项目目录里，而不是留在聊天记录里。

它更不是图像生成服务。技能本身不绑定任何模型；它约束的是生成之后的事情：
事实核对、素材准入、二维码重生成、交付检查。

## 三个关键取舍

### 1. 路由，而不是一条万能流程

新建、改稿、编辑器精修、导出交付，四件事的上下文完全不同。
一条万能流程会让改一张日期的图也重跑需求确认。
所以 <code>SKILL.md</code> 只负责路由，四条路由各自持有自己的过程文件，
并且**明确禁止交叉加载**——支持文档是细化，不是竞争。

### 2. 强制加载顺序

入口文件只放"全局纪律 + 路由表"，细节全部下沉到 <code>workflows/</code>、
<code>references/</code>、<code>templates/</code>。
这样在任何一次调用里，Agent 读的都是当前任务需要的那部分，
而不是把整个技能包塞进上下文。

### 3. 机器能查的交给机器

尺寸、色彩模式、文件可读性、二维码可解码性——这些有确定答案，就用脚本查。
留在人工环节的只有四件机器查不了的事：远看是否可读、文案事实是否正确、
真机是否扫得动、素材是否可用。
交付报告会把这四件事显式列出来，而不是含糊地写"已检查"。

## 交付红线为什么是这六条

| 红线 | 背后的一次真实返工 |
|---|---|
| 二维码不重绘、不目测 | 截图里的码静区被裁、指向过期链接 |
| 产品外观与包装文字不自由改 | 改一个字就把功效宣称改了 |
| 每份素材有授权状态 | 字体无法印刷授权 |
| 印刷与社交分开出文件 | 同一张图在两个渠道都"能用"，但都不合格 |
| 交付必须跑检查 | 尺寸错了才发现 |
| 字体要么可嵌入要么可授权 | 客户机器上没有字体 |

这些是**硬约束**，不是建议。它们的存在本身就是技能的价值所在。

## 仓库形态

仓库按 [hugohe3/ppt-master](https://github.com/hugohe3/ppt-master) 的公开结构组织：
插件市场清单、<code>skills/</code> 下的技能本体、双语文档、落地页、可下载压缩包。
原因是这类技能真正的用户是"另一个 Agent"，
它需要的是**装得上、找得到、读得懂**的仓库，而不是一个漂亮的 README。

## 能改什么

| 想改 | 改哪里 | 注意 |
|---|---|---|
| 流程、提问顺序 | <code>skills/poster-master/workflows/</code> | 保持"一条路由一份过程文件" |
| 专业判断 | <code>skills/poster-master/references/</code> | 一篇一个主题，别写成手册 |
| 项目文档模板 | <code>skills/poster-master/templates/</code> | 改字段名要同步 <code>new_project.js</code> |
| 脚本行为 | <code>skills/poster-master/scripts/</code> | 改完跑一次示例工程回归 |
| 入口与红线 | <code>skills/poster-master/SKILL.md</code> | 红线不要为了省事删掉 |

不要引入的：通用脚手架结构（<code>tests/</code>、CI 模板、worktree 约定）、
大模型权重、第三方字体、客户素材。

## 改完怎么验

```bash
python "<技能目录>/scripts/quick_validate.py" "<技能目录>"
node "<技能目录>/examples/build-demo.js"
python "<技能目录>/scripts/render_preview.py" \
  --source "<技能目录>/examples/城市夜跑/城市夜跑-组件源稿.poster.json" \
  --output "$TMPDIR/preview.png"
python "<技能目录>/scripts/check_delivery.py" --project "<技能目录>/examples/城市夜跑"
```

交付检查必须 **0 项失败**。示例工程是回归基线：它自己过不了，技能就是坏的。
