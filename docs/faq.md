# 常见问题

[English](en/faq.md) · [文档索引](README.md)

**Q：它会自动出图吗？**

会，但先过门禁。默认路由会先问几个真正影响设计的问题；说"别问直接出稿"就走 Quick 档，
假设会被标注出来，交付门仍然关闭。

**Q：一定要装 Python 依赖吗？**

不用。编辑器和项目脚手架是纯 Node 标准库。只有用 Python 脚本（渲染、检查、PSD、二维码、抠图）
时才需要 <code>pip install -r requirements.txt</code>。

**Q：为什么二维码不能直接用客户给的那张图？**

因为它可能是截图、被裁掉了静区、或者指向一个已经过期的群。技能的做法是：解码 → 与客户确认的
链接逐字符比对 → 用确认后的链接重新生成 → 真机实测。

**Q：交付检查说"未检测到二维码"，是失败吗？**

不是失败，是提示。检查脚本无法知道这张图是否本该有二维码。如果这张海报确实应该有码，
说明码有问题，需要人工处理。

**Q：交付检查说"检测到二维码图形，但无法解码"？**

这是失败项。常见原因：模块没有落在整数像素上（重新按最终尺寸生成）、
被平滑插值糊掉（用 <code>"resample": "nearest"</code>）、静区被裁、对比度不足、
或码在成品尺寸下太小（每模块至少 3 px，数字稿里的常见码至少 150 px）。

**Q：编辑器和 Agent 改出来的东西会不一样吗？**

不会。两者渲染同一份组件源稿，同一套尺寸、层级、字号规则。差异只在交互方式。

**Q：可以只做某一阶段吗？**

可以。交付路由、修改路由都可以单独进入。但跳过前置阶段的部分，
Agent 必须在状态报告里明确标注"哪些内容是未经确认的假设"。

**Q：素材可以用网上找的图吗？**

可以，但必须登记来源和授权状态。授权状态未知的素材不进交付物。

**Q：能接我们自己的模型做生图吗？**

生图只是一个环节，技能包定义的是"生图之后怎么审、怎么用"：
出图后必须核对事实（人数、价格、日期、标语），核对与已有版式的关系，再进入素材台账。

**Q：中文/英文海报都能做吗？**

能。语言跟随用户与素材语言；字体授权仍需单独确认。

**Q：技能包能改吗？**

能，它就是一堆 Markdown、JSON 和脚本。先读 [为什么这样设计](why-poster-master.md)，
再读 [CONTRIBUTING.md](../CONTRIBUTING.md)。
