把一句需求和一堆客户素材，变成可直接交付的海报。

Poster Master 是一个 Agent 技能包：它接管做海报的全过程——文案层级、视觉方向、初稿迭代、组件源稿，以及 PNG / SVG / 分层 PSD 的交付与检查。

安装技能 查看仓库

试试看：$poster-master 帮我做一张骑行社团招新海报，尺寸 A3，链接 https://example.com/join

海报交付里，最容易翻车的四件事

它们都不是审美问题，而是可以被规则挡住的问题。

01

文案事实不能猜

日期、价格、地点、报名链接未经确认就只能是待确认项，不能填一个看起来合理的值。

02

二维码永远不重绘

解码原码 → 与确认链接逐字符比对 → 重新生成干净码 → 真机实测，缺一不可。

03

印刷与社交是两个文件

同一张图不静默复用。尺寸、出血、色彩模式、文件格式按载体分别出。

04

交付靠检查，不靠眼睛

脚本核对尺寸、色彩模式、文件完整性与二维码可解码性，并明确列出机器查不了的四件事。

六阶段，一条可回溯的流水线

阶段属于海报，不属于路由。改稿时从拥有这个改动的阶段重新进入。

1 · 目标受众、主要效果、核心信息、成功标准
2 · 信息带优先级标签的文案集、待确认问题
3 · 方向视觉关键词、配色、字体、主视觉
4 · 初稿至少一张实际尺寸可读的构图
5 · 迭代带决策的版本化反馈记录
6 · 交付分渠道 PNG / SVG / PSD + 交付检查

组件源稿

不是一张图，是一个 JSON：图层分组、每个元素的文字与位置。别人能接着改。

零依赖编辑器

纯 Node 标准库，本地起服务，画布改稿，导出 PNG / SVG / 分层 PSD。不用 npm install。

脚本化检查

脚手架、无头渲染、交付检查、PSD 写出、二维码提取与重生成、抠图边缘报告。

装上就能用

不需要改你的工作流，也不需要为每个 Agent 单独适配。

Claude Code

/plugin marketplace add Ilovegood123isgad/Poster_master
/plugin install poster-master@poster-master

Codex / 任意 Agent

curl -LO https://github.com/Ilovegood123isgad/Poster_master/releases/download/v1.0.0/poster-master-skill-v1.0.0.zip
unzip poster-master-skill-v1.0.0.zip -d ~/.codex/skills/

Git 克隆

git clone https://github.com/Ilovegood123isgad/Poster_master.git
cp -R Poster_master/skills/poster-master ~/.codex/skills/

编辑器与项目脚手架零依赖；只有渲染、检查、PSD、二维码脚本需要 pip install -r requirements.txt。
