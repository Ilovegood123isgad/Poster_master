# Information Hierarchy

Read in stage 2 (copy sheet). Adapted from the client-intake matrix.

## The client did not send "copy"

What arrives is a mixed dump of different information types. Sort before designing:

| Type | What it is | Examples | Handling |
|---|---|---|---|
| Propagation facts | What is true and must be understood | Title, theme, date, place, price, rules, eligibility | Highest accuracy; needs a source and a confirmation state |
| Action entries | How to act | QR, URL, phone, WeChat ID, sign-up form, ticket link | Must be tested; the action is the point of the poster |
| Identification assets | Who is behind it | Logo, brand mark, organisation name, sponsor marks | Rights-controlled; never restyled |
| Rule constraints | What is allowed | "Free entry", "18+ only", "Limited to 30 people", disclaimers | Must survive the layout; never cropped away for space |
| Carrier delivery | How the file is used | Print size, bleed, colour, deadline, file name | Decides the export set |
| Decision ownership | Who signs off | Client contact, approver, on-site owner | Decides who confirms what, and when |

## Priority tags

Tag every line, per version:

| Tag | Meaning | Treatment |
|---|---|---|
| **P0** | The viewer must get this, or the poster fails | Never removed, never below the fold, never shrunk below legibility |
| **P1** | Should be present and findable | Removed only if it collides with a P0, and only with a recorded decision |
| **P2** | Nice to have | Dropped first under pressure |

Tag per **version**, not per poster. A phone-screen version and a print version rarely share
the same P0 list — the print version can carry the address block, the phone version can carry
the map pin instead.

## Reading order

Not every poster reads top-to-bottom. Choose the path the design implies and make it explicit:

| Pattern | Structure | Fits |
|---|---|---|
| Inverted pyramid | Big claim → supporting detail → action | Notices, recruitment, offers |
| Z-pattern | Top-left → top-right → bottom-left → bottom-right | Landscape, web-style, screen |
| Centre-out | Central key visual, text radiating | Brand, festival, atmosphere |
| Columnar | Parallel columns of equal content | Schedules, multiple tracks, services |
| Layered depth | Foreground action, midground subject, background context | Editorial, product, event |
| Route | A path through the poster (arrows, steps) | Wayfinding, process, multi-step |

State the intended path in the direction sheet. If two elements both claim the first-read
position, the poster has no first read.

## Copy writing rules for posters

1. **Headlines are not sentences.** A headline names the thing. The supporting line gives the
   reason to care.
2. **Numbers are the strongest element.** A date, a price, a count, or a deadline in large type
   does more work than a paragraph.
3. **One claim per block.** If a paragraph needs two commas and an "and", it is two lines.
4. **Write the CTA as a verb with an object**: "扫码报名", "进群领资料", "预约参观" — not
   "欢迎咨询" with no destination.
5. **Do not repeat the logo as a headline.** The organisation name is identification, not a
   message.
6. **Mind the line breaks.** A line break that separates a number from its unit, or a place
   from its date, costs comprehension.
7. **Chinese and Latin text need different spacing.** Set a real gap; do not let the renderer
   decide.

## The copy sheet

Use `../templates/02-文案层级表.md`. It records, per line: content, type, priority per
version, source, confirmation state, owner, and the character budget.

**Character budget** matters: a headline that must fit one line at 96 px has a limit, and
discovering it after the layout is built means a re-layout, not a one-word change.

## Open questions

A separate table, not a paragraph. Columns: question, why it matters, who owns it, deadline,
status, and what the design will do in the meantime (a labelled placeholder, or omit).

An open question that is answered by "the designer decided" is a defect in the process, not a
solution. Design decisions fill **layout** gaps, never **fact** gaps.
